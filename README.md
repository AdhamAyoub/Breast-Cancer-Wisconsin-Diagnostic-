# 🧬 Breast Cancer Wisconsin (Diagnostic) Dataset

This repository uses the **Breast Cancer Wisconsin (Diagnostic)** dataset, a widely used dataset for binary classification tasks in machine learning, particularly for cancer diagnosis models.

---

## 📊 About the Dataset

Features are computed from digitized images of **fine needle aspirates (FNA)** of breast masses. These features describe the **cell nuclei** characteristics present in each image.

> Based on the work:
> *K. P. Bennett and O. L. Mangasarian (1992), "Robust Linear Programming Discrimination of Two Linearly Inseparable Sets", Optimization Methods and Software 1, pp. 23-34.*
